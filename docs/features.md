# Terminal Features Deep-Dive

ForexPulse Pro is packed with tools designed to provide a comprehensive analytical environment.

## 1. Multi-Chart Analysis

The **Multi-Chart** page allows you to monitor up to 4 currency pairs simultaneously in a 2x2 grid.

- **Independent Tracking**: Each chart is a separate instance with its own price feed.
- **Sync Feature**: Use the "Sync Timeframe" button to align all charts to the same interval (e.g., set all to 4H for top-down analysis).
- **Fullscreen Mode**: Use the panel toggle (bottom-right) to hide sidebar elements and give the charts maximum space.

## 2. Market Sessions Tracker

Located in the Sidebar, this tool tracks global liquidity centers.

- **Sessions**: Sydney, Tokyo, London, and New York.
- **Session Overlaps**: High-volatility opportunities often occur when two sessions overlap (e.g., London and New York).
- **Collapsible**: Toggle the header to save space when you don't need to monitor session hours.

## 3. Trade Suggestions (Signals)

The **Signals** page scans your watchlist to find high-probability setups.

- **Multi-Indicator Logic**: Signals are generated using a combination of RSI, MACD, EMA Crosses, and Bollinger Bands.
- **Confidence Rating**: Each signal includes a strength percentage (e.g., 85%).
- **Market Context**: Reasons like "RSI Oversold" or "Bullish Trend" are provided to explain the "Why" behind every suggestion.

## 4. Performance Journal

The **Journal** page is where you review your history.

- **Categorization**: Add notes and tags (#news-trade, #scalp) to your trades.
- **Analysis**: Use the Journal to identify which strategies are working and which are losing money.

## 5. Economic Calendar

Stay ahead of market-moving news.

- **Impact Rankings**: High (Red), Medium (Orange), and Low (Yellow) impact events.
- **Real-Time Counters**: Know exactly how many minutes are left before a major news release.
